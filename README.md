# تخطيط الدخل — Income Planning

موقع لتنظيم الدخل والمصروفات ومراكز التكلفة والاستثمار، بالجنيه المصري، مع تجميع تلقائي:
**عملية → شهر → سنة → إجمالي**. البيانات مخزّنة في قاعدة بيانات مشتركة، فأي تعديل يظهر لكل من يفتح الموقع.

## المزايا

- **الصفحة الرئيسية:** أرقام إجمالية (دخل / مصروفات / استثمار / المتبقّي) + بطاقات للسنوات.
- **بطاقة السنة:** إجماليات السنة + 12 بطاقة شهرية.
- **بطاقة الشهر:** جداول الدخل والمصروفات والاستثمار (إضافة/تعديل/حذف) + لوحة «الخطة مقابل الفعلي».
- **تصنيف المصروفات** حسب النوع + الشخص (مراكز التكلفة).
- **عملات متعددة** (جنيه / ريال / دولار) بسعر تحويل يدوي لكل عملية، والملخّص دائماً بالجنيه.
- **مصادر دخل ثابتة** تتكرر شهرياً بضغطة، + دخل طارئ.
- **وجهات استثمار** تحددها أنت، بنسبة وهدف اختياريين، مع متابعة التقدّم.

## التقنية

- Next.js 15 (App Router) + React 19 + TypeScript
- Tailwind + تصميم عربي RTL
- Drizzle ORM + Postgres (Neon) عبر درايفر HTTP (مناسب للـ serverless)

## التشغيل محلياً

```bash
npm install
cp .env.example .env   # ثم ضع DATABASE_URL
npm run db:generate    # توليد ملفات SQL (مرة واحدة بعد تغيير الـ schema)
DATABASE_URL="..." node scripts/migrate.mjs   # إنشاء الجداول عبر HTTP
npm run dev
```

## النشر (Vercel)

1. اربط المستودع بمشروع على Vercel.
2. أضف قاعدة بيانات Neon من Vercel Marketplace (تضبط `DATABASE_URL` تلقائياً).
3. بعد أول نشر، شغّل إنشاء الجداول مرة واحدة: `DATABASE_URL="<neon url>" node scripts/migrate.mjs`.

> ملاحظة أمان: الموقع يعتمد على «لينك سري» بدون تسجيل دخول. شارك الرابط بحذر.
